
# ISO 27001 Control Mapping

| Control Area | Platform Implementation |
|---|---|
| Access control | IAM and RBAC |
| Secure development | SAST and code review |
| Vulnerability management | Dependency and container scanning |
| Logging and monitoring | Prometheus, Grafana, Alertmanager |
| Configuration management | Terraform and Git |
| Incident management | Incident response runbooks |

This mapping is for learning and demonstration. It does not establish certification.
