
# NIST Cybersecurity Framework Mapping

| Function | Platform Control |
|---|---|
| Govern | Security policies and ownership |
| Identify | Asset and infrastructure inventory |
| Protect | IAM, secure coding, hardening |
| Detect | Security scanning and monitoring |
| Respond | Incident response procedures |
| Recover | Backup and recovery procedures |

This is a practical learning mapping, not a formal assessment.
