
# OWASP Security Mapping

| Security Area | Platform Control |
|---|---|
| Access control | IAM, Kubernetes RBAC |
| Cryptography | TLS, encryption at rest |
| Injection | Secure coding and SAST |
| Security configuration | Terraform and Kubernetes policy checks |
| Vulnerable components | Dependency and image scanning |
| Authentication | Identity integration and least privilege |
| Logging | Application and infrastructure monitoring |

This document is an engineering control mapping, not a claim of formal compliance.
